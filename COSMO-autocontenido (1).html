3. Determinación del centro de presión (CP)

Método algorítmico (Python)

ProgramaParaCalcularCP.py
# ==========================================
# 2. Variables con las dimensiones del cohete
# ==========================================
alto_cono = 9.0       
ancho_cono =3.5       
largo_cuerpo = 31.5    

cuerda_aleta = 5.0    
ancho_aleta = 2.5      
numero_aletas = 4      

factor_influencia = 1 + (numero_aletas * ancho_aleta) / (ancho_cono * 3)

area_cono = (ancho_cono * alto_cono) / 2
area_cuerpo = ancho_cono * largo_cuerpo

area_una_aleta = cuerda_aleta * ancho_aleta
area_aletas_total = area_una_aleta * numero_aletas

area_aletas_efectiva = area_aletas_total * factor_influencia

# 5. Ubicación de los Centroides (medidos desde la punta)
x_cono = (2 / 3) * alto_cono
x_cuerpo = alto_cono + (largo_cuerpo / 2)
x_aletas = alto_cono + largo_cuerpo - cuerda_aleta/2

# ==========================================
numerador = (area_cono * x_cono) + (area_cuerpo * x_cuerpo) + (area_aletas_efectiva * x_aletas)
denominador = area_cono + area_cuerpo + area_aletas_efectiva

cp = numerador / denominador

# ==========================================
# 7. Impresión del valor final
# ==========================================
print(f"El Centro de Presión (CP) es: {cp:.2f}")

Cómo funciona el programa

El programa divide el cohete en tres figuras (cono triangular, cuerpo rectangular y cuatro aletas), calcula el área y el centroide de cada una medido desde la punta y obtiene el promedio ponderado por área. A las aletas se les aplica un factor de influencia (1.95) porque aportan más fuerza normal que su área geométrica.

6. Conclusiones generales

Margen de estabilidad: CM vs. CP

El cohete es estable cuando el CM queda delante del CP, es decir, más cerca de la punta. Con el CP del programa (29.21 cm) y un calibre de 3.5 cm:

ConfiguraciónCM (cm)Margen (calibres)Estado
Cono vacío33.0−1.08Inestable
Cono + 6.20 g30.8−0.45Inestable
Cono + 12.40 g28.8+0.12Estable
Cono + 18.60 g27.1+0.60Estable

Margen = (CP − CM) / calibre. Un valor positivo indica CM delante del CP.

Síntesis grupal

A través de la práctica, el equipo COSMO Aerospace comprobó cuantitativamente las Leyes de Newton y los principios de mecánica de fluidos en el cohete “Vergarus”, validando la importancia del margen de estabilidad estática entre CM y CP mediante herramientas experimentales y de software (Tracker).
